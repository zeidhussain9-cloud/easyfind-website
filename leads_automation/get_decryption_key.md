# Getting WhatsApp Decryption Key (Non-Rooted Phone)

## Method: WhatsApp Key-DB-Extractor

Since your phone is NOT rooted, we'll use this tool to extract the decryption key.

### Requirements:
- ✅ Phone connected via USB
- ✅ File transfer mode enabled
- ⏳ Enable USB Debugging (I'll help you with this)
- ⏳ Install ADB on Mac (I'll do this automatically)

### What We'll Do:
1. Enable USB Debugging on your phone (takes 30 seconds)
2. Install Android Debug Bridge (ADB) on your Mac
3. Run the extractor tool to get the key
4. Extract your WhatsApp messages

### Enable USB Debugging (Do This While Waiting):

**Step 1: Enable Developer Options**
1. Open Settings on your phone
2. Go to "About Phone"
3. Find "Build Number"
4. Tap "Build Number" 7 times rapidly
5. You'll see: "You are now a developer!"

**Step 2: Enable USB Debugging**
1. Go back to main Settings
2. Find "Developer Options" (now visible)
3. Enable "USB Debugging"
4. When prompted, tap "Allow"

**Step 3: Authorize Your Computer**
- A popup will appear on your phone: "Allow USB debugging?"
- Check "Always allow from this computer"
- Tap "OK"

### When Done:
Type "debugging enabled" and I'll continue with extraction.
